# Mafia Tracker

A single-file, offline-friendly note-taking tool for social-deduction (Mafia) games:
roster & reads grid, vote tracker (voters / non-voters / majority), night/kill log,
role & claim tracking, parity-cop chain, and Markdown/TXT export.

All game data is stored locally in your browser (localStorage), nothing is uploaded.

**Live:** https://akulik1990.github.io/mafia-tracker/
